# randname 使用指南

randname 是一個以名單抽取為主的桌面程式，提供單抽、多抽、減量抽與滾動單抽四種模式。本文說明安裝、操作、設定與常見問題。

## 1. 安裝與啟動

### 使用已編譯版本

1. 從專案的 GitHub Releases 下載適合作業系統的版本。
2. 解壓縮至可寫入的資料夾。
3. 執行其中的 `randname`（Linux）或 `randname.exe`（Windows）。

程式第一次啟動會顯示啟動畫面，至少停留一秒；若載入時間較長，啟動畫面會等主視窗準備完成後才關閉。

### 從原始碼啟動

需要 Python 3.12.10 與 PySide6 6.11.1。於專案根目錄建立虛擬環境並安裝 PySide6：

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install PySide6==6.11.1
python main.py
```

Windows PowerShell 的虛擬環境啟用指令為 `.venv\Scripts\Activate.ps1`；其餘安裝指令相同。若不使用虛擬環境，請確認 `python` 指向相容的 Python 版本。

### 自行編譯

專案附有 [`build_linux.sh`](../build_linux.sh) 與 [`build_windows.bat`](../build_windows.bat)。依目標平台安裝相應版本的 Python、PySide6 與 Nuitka 後，執行對應腳本；編譯輸出位於 `build/`。建置參數與檔案收集設定以腳本內容為準。

## 2. 主視窗與模式切換

主視窗上方的「模式」選單可切換抽取頁面；切換頁面不會清除名單。啟動時顯示哪個模式由 `doc/config.toml` 的 `app.default_mode` 決定，預設為 `ScrollSingle`。視窗下方的狀態列會顯示最近一次操作結果或狀態。

### 單抽（Single）

1. 在「模式」選單選取「單抽」。
2. 按頁面中央的「抽取」按鈕。
3. 抽中姓名會顯示在結果區，狀態列同步回報結果。

每次單抽都從目前完整名單中隨機選一人；抽中者不會因此從名單移除，下次仍可能抽到同一人。

### 多抽（Multi）

1. 選取「多抽」。
2. 使用數量旁的 `+`、`-` 按鈕設定本次人數，最少為 1，最多為目前名單人數。
3. 按「抽取」執行。

同一次多抽不會重複抽到同一人；不同次多抽彼此獨立，名單不會永久扣除已抽中的人。結果區會顯示所有抽中姓名。

### 減量抽（Lift）

1. 選取「減量抽」。
2. 設定本次抽取數量，再按「抽取」。
3. 後續抽取會從上次剩餘名單中繼續選人。
4. 按「重置」可恢復使用完整名單重新抽取。

減量抽的剩餘名單只在目前程式執行期間保留；關閉程式後不會延續。每次抽取數量不可大於剩餘人數。

### 滾動單抽（ScrollSingle）

1. 選取「滾動單抽」。
2. 按「開始」讓姓名在結果區輪播。
3. 按「停止」結束輪播，當下顯示的姓名即為結果。

輪播速度由 `scroll_single.rate` 設定，數值代表每秒更新次數。每輪名單播完後會重新洗牌。停止結果會寫入最近結果與記錄檔。

## 3. 名單與設定

設定檔為 [`doc/config.toml`](../doc/config.toml)，格式是 TOML。程式啟動時讀取一次；檔案不存在或無法解析時，會嘗試使用 `.config.default.toml`，並提示目前正在使用備援設定。  
**建議修改前先備份設定檔。**

目前設定檔包含以下區段：

| 區段 | 欄位 | 說明 |
| --- | --- | --- |
| `[app]` | `name` | 程式名稱。 |
| `[app]` | `default_mode` | 啟動模式，支援 `Single`、`Multi`、`Lift`、`ScrollSingle`。 |
| `[app]` | `theme` | 啟動時使用的主題名稱；預設為 `randname`，需對應 `theme/` 中的 TOML 檔名（不含副檔名）。 |
| `[splash]` | `duration_ms` | 啟動畫面最短顯示時間，單位為毫秒；預設為 `1000`。 |
| `[window]` | `width`、`height` | 主視窗啟動尺寸，皆須為正整數。 |
| `[scroll_single]` | `rate` | 滾動單抽每秒更新次數，須為正整數。 |
| `[names]` | 名單項目 | 每個鍵為識別碼、每個值為顯示姓名。 |

名單格式範例：

```toml
[names]
"student-001" = "王小明"
"student-002" = "陳小華"
```

每位參與者須使用唯一鍵值。編輯 `doc/config.toml` 後，重新啟動程式可載入所有設定。選單「檔案 -> 重新載入配置」會重新載入名單、重新掃描 `theme/` 並套用設定中指定的主題，新增、修改或移除有效主題後可立即同步主題選單；不會改變視窗尺寸或啟動模式。

## 4. 主題

啟動主題由 `app.theme` 指定；執行期間可從「主題」選單切換。程式會讀取 `theme/*.toml` 中有效的主題檔，因此也可以複製既有 TOML 檔並調整顏色，建立自訂主題。自訂主題須包含 `[colors]` 區段；格式可參考同目錄的主題檔。新增或編輯主題後，使用「檔案 -> 重新載入配置」即可重掃主題目錄並套用目前配置的主題，無須重啟程式。

## 5. 記憶與記錄

- `doc/memory.json`：保存匯入/匯出的記憶資料與各模式最近結果。
- `doc/log.log`：記錄設定載入、抽取結果與錯誤等事件。
- 「檔案 -> 匯入...」：選擇 JSON 記憶檔，匯入後套用其中的名單（若有）與最近結果；不會覆寫 `doc/config.toml`。
- 「檔案 -> 匯出...」：將目前記憶資料另存為 JSON。

記憶檔與設定檔用途不同。若要更換日常使用的名單，請修改 `doc/config.toml`；若要備份或搬移最近結果，請使用記憶匯入/匯出。

## 6. 常見問題

**按下抽取後沒有結果**

確認目前使用的設定中 `[names]` 至少有一筆有效名單，且使用最新版本程式。空名單無法執行抽取；請檢查 `doc/config.toml` 是否有拼字、引號或 TOML 格式錯誤。

**多抽或減量抽沒有抽出指定數量**

多抽數量不得超過名單總數；減量抽數量不得超過目前剩餘名單數。減量抽可按「重置」恢復完整名單。

**設定修改後畫面沒有變化**

「重新載入配置」會更新名單與主題；預設模式及視窗尺寸會在程式啟動時套用，修改後請重新啟動。

**設定檔無法載入**

確認 `doc/config.toml` 是有效 TOML，尤其注意字串引號與區段標題。若主設定無法讀取，程式會嘗試使用 `.config.default.toml`；若兩者都不可用，請還原有效設定檔後重新啟動。
