# randname 使用指南（简体中文）

randname 是一款用于课堂点名和名单抽取的桌面程序，提供单抽、多抽、减量抽和滚动单抽四种模式。本文介绍安装、使用、配置和常见问题。程序界面目前使用简体中文。

语言版本： [繁體中文](使用指南.md) | [English (US)](User_Guide_en-US.md)

## 1. 安装与启动

### 使用预编译版本

1. 从项目的 [GitHub Releases](https://github.com/HQZ-OhNone/randname/releases) 下载适用于操作系统的版本。
2. 将压缩包解压到可写入的目录。
3. 运行其中的 `randname`（Linux）或 `randname.exe`（Windows）。

启动时会显示启动画面，至少显示一秒；如果程序初始化时间较长，启动画面会等主窗口准备好后再关闭。

### 从源代码运行

需要 Python 3.12.10 和 PySide6 6.11.1。在项目根目录创建虚拟环境并安装 PySide6：

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install PySide6==6.11.1
python main.py
```

Windows PowerShell 激活虚拟环境的命令是 `.venv\Scripts\Activate.ps1`，其余安装命令相同。若不使用虚拟环境，请确认 `python` 指向兼容版本。

### 自行编译

项目提供 `build_linux.sh` 和 `build_windows.bat`。根据目标平台安装相应版本的 Python、PySide6 和 Nuitka，然后运行对应脚本；编译输出位于 `build/`。具体构建参数和资源收集方式以脚本为准。

## 2. 主窗口与模式

通过主窗口顶部的“模式”菜单切换页面。切换模式不会清空名单。启动后默认显示的模式由 `doc/config.toml` 中的 `app.default_mode` 决定，默认值为 `ScrollSingle`。窗口底部的状态栏会显示最近操作的结果或状态。

### 单抽（Single）

1. 在“模式”菜单中选择“单抽”。
2. 点击页面中央的“抽取”按钮。
3. 抽中的姓名会显示在结果区域，状态栏也会显示结果。

每次单抽都从完整名单中随机选择一人。抽中后不会将此人从名单中移除，因此后续仍可能再次抽中。

### 多抽（Multi）

1. 选择“多抽”。
2. 使用人数旁的 `+`、`-` 按钮设置本次抽取人数，最少为 1，最多为当前名单人数。
3. 点击“抽取”。

同一轮多抽不会重复抽中同一个人；不同轮次互相独立，抽取结果不会从名单中永久移除。结果区域会显示本轮所有姓名。

### 减量抽（Lift）

1. 选择“减量抽”。
2. 设置本次人数并点击“抽取”。
3. 后续抽取会从上次剩余名单中继续选择。
4. 点击“重置”可恢复完整名单并重新开始。

剩余名单只在当前程序运行期间保留，关闭程序后不会继续。每次抽取人数不能超过当前剩余人数。

### 滚动单抽（ScrollSingle）

1. 选择“滚动单抽”。
2. 点击“开始”，姓名会在结果区域滚动显示。
3. 点击“停止”；停止时显示的姓名就是本次结果。

滚动速度由 `scroll_single.rate` 设置，表示每秒更新次数。每轮名单显示完后会重新洗牌。停止结果会写入最近结果和日志。

## 3. 名单与配置

配置文件为 `doc/config.toml`，格式为 TOML。程序启动时读取一次。如果文件不存在或无法解析，程序会尝试使用项目根目录下的 `.config.default.toml`，并提示正在使用备用配置。修改前建议备份文件。

| 配置区段 | 字段 | 说明 |
| --- | --- | --- |
| `[app]` | `name` | 程序名称。 |
| `[app]` | `default_mode` | 启动模式，可设为 `Single`、`Multi`、`Lift` 或 `ScrollSingle`。 |
| `[app]` | `theme` | 启动主题名称；默认值为 `randname`，对应 `theme/` 中 TOML 文件名（不含扩展名）。 |
| `[splash]` | `duration_ms` | 启动画面最短显示时间，单位为毫秒；默认值为 `1000`。 |
| `[window]` | `width`、`height` | 主窗口启动尺寸，必须是正整数。 |
| `[scroll_single]` | `rate` | 滚动单抽每秒更新次数，必须是正整数。 |
| `[names]` | 名单条目 | 每个键是唯一标识符，每个值是显示姓名。 |

名单示例：

```toml
[names]
"student-001" = "王小明"
"student-002" = "陈小华"
```

每位参与者应使用唯一键。修改 `doc/config.toml` 后，重启程序可应用全部配置。菜单“文件 -> 重新加载配置”会重新载入名单、扫描 `theme/` 并应用配置中指定的主题；新增、修改或删除有效主题后可立即同步主题菜单。此操作不会改变窗口尺寸或启动模式。

## 4. 主题

启动主题由 `app.theme` 指定，运行期间可通过“主题”菜单切换。程序会读取 `theme/*.toml` 中有效的主题文件。要添加自定义主题，可复制现有文件并修改颜色；自定义文件必须包含 `[colors]` 区段，格式可参考同目录的主题文件。新增或编辑主题后，使用“文件 -> 重新加载配置”即可重新扫描主题目录并应用当前配置指定的主题，无需重启。

## 5. 记忆与日志

- `doc/memory.json`：保存导入/导出的记忆数据和各模式最近结果。
- `doc/log.log`：记录配置加载、抽取结果和错误等事件。
- “文件 -> 导入...” ：选择 JSON 记忆文件。导入后会应用其中的名单（如果有）和最近结果，但不会覆盖 `doc/config.toml`。
- “文件 -> 导出...” ：将当前记忆数据另存为 JSON。

记忆文件和配置文件用途不同。要更换日常使用的名单，请编辑 `doc/config.toml`；要备份或迁移最近结果，请使用记忆导入/导出。

## 6. 常见问题

**点击抽取后没有结果**

确认当前使用的配置中 `[names]` 至少有一条有效记录，并检查 `doc/config.toml` 是否存在拼写、引号或 TOML 格式错误。空名单无法抽取。

**多抽或减量抽没有抽出指定人数**

多抽人数不能超过名单总人数；减量抽人数不能超过剩余人数。减量抽可点击“重置”恢复完整名单。

**修改配置后界面没有变化**

“重新加载配置”会更新名单和主题；默认模式和窗口尺寸在程序启动时应用，修改后需要重启。

**配置文件无法加载**

检查 `doc/config.toml` 是否为有效 TOML，尤其是字符串引号和区段名称。主配置无法读取时，程序会尝试使用 `.config.default.toml`；如果两者都不可用，请恢复有效配置后重启。
