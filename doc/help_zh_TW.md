# randname 說明

randname 是用於課堂點名的桌面程式。「模式」選單提供單抽、多抽、減量抽、滾動單抽、滾動多抽與滾動減量抽。

## 抽取方式

- **單抽：** 不是獨立頁面，而是自動切到多抽並將人數設為 `1` 的快捷方式。
- **多抽：** 使用數量旁的加減按鈕設定人數，再按「抽取」。同一次抽取不會重複選中同一人；下一次抽取會重新使用完整名單。
- **減量抽：** 本次抽中的人會從目前執行期間的剩餘名單移除。「重設」會恢復目前名單。切換名單或重新整理後名單內容有變時，剩餘名單會重設。
- **滾動單抽：** 不是獨立頁面，而是自動切到滾動多抽並將人數設為 `1` 的快捷方式。
- **滾動多抽：** 先設定人數，按「抽取」後顯示相應數量的固定格子並同時輪播。第一次抽取時會決定格子位置（例如 6 人排成 3×2、置中顯示），之後每按一次「停止」固定一個名字，已固定的名字不會因其他名字滾動而移動。若某個名字過長，程式會重新調整格子或字號並鎖定；下一輪抽取或更改人數時重新佈局。本輪已停下的名字不會再次出現。滾動速度由 `scroll.rate` 控制。
- **滾動減量抽：** 滾動與固定格子方式與滾動多抽相同，但本輪抽中的名字會從剩餘名單移除；右側「重設」按鈕恢復完整名單。滾動速度同樣由 `scroll.rate` 控制。

輸出框會保持視窗大小不變：非滾動模式的名字能單行顯示時單行顯示，放不下且高度足夠時自動換行，仍然放不下時縮小字號；滾動模式把每個名字放在固定格子中，只有名字放不進格子時才縮小字號。

## 名單

從「名單」選單切換名單。名單設定位於 `config/name.toml`；每組名單有固定鍵名、多語言顯示名稱和人員清單：

```toml
[rosters.class_1.name]
en_US = "Class 1"
zh_CN = "一班"
zh_TW = "一班"

[rosters.class_1.names]
"student-001" = "王小明"
"student-002" = "陳小華"
```

每位人員須使用唯一鍵。名單名稱依目前介面語言、系統語言、英語、名單鍵名順序回退。主要名單無法使用時，程式會嘗試 `.name.default.toml`，最後使用內建的一人名單。

## 語言與主題

在「語言」選單選擇介面語言。語言包位於 `config/language.toml`，其中 `preferred` 指定首次啟動的首選語言；舊設定中的 `app.language` 僅作為後備，`language.toml` 的 `preferred` 優先。英語為內建語言，語言檔缺失時仍可使用。切換語言會立即生效，不會清除目前抽取結果。

主題集中保存在 `config/theme.toml`，其中 `default` 設定預設回退主題。主題名稱與名單名稱使用相同的多語言回退順序。

程式不會記住上次使用的主題、名單、日誌等級、模式、語言、數量或視窗尺寸；每次啟動都從設定檔與獨立設定檔讀取，保證介面狀態一致。記憶檔只用於儲存和匯入/匯出各模式的最近結果。

## 視窗與狀態列

主視窗預設允許拖動邊緣拉伸，但下次啟動仍使用 `[window]` 中設定的初始尺寸，不會記住上次拉伸後的尺寸。視窗尺寸不會因為名字過長或匯入記憶而改變。

狀態列左側顯示「抽取完成」等臨時訊息，右側顯示目前模式、名單、數量、主題、語言、日誌等級與版本號。可在 `[statusbar]` 中逐項隱藏。

## 設定

在 `config/config.toml` 設定啟動模式、名單、啟動畫面、視窗尺寸、輸出字號、滾動速度、檢視器、狀態列與日誌等級；主題與語言分別以 `theme.toml`、`language.toml` 獨立設定檔為準。設定檔內每個選項都有中文註解。

```toml
[window]
size_mode = "screen_ratio"   # 或 "fixed"
screen_ratio = 0.75          # 初始尺寸占可用螢幕的比例
aspect_ratio = 1.5
width = 1000
height = 600
resizable = true

[scroll]
rate = 30

[splash]
enabled = true
mode = 1
duration_ms = 1000
screen_ratio = 0.25
```

比例模式下，啟動畫面不超過可用螢幕的 `screen_ratio`；主視窗按 `screen_ratio` 與 `aspect_ratio` 計算初始尺寸。啟動畫面 `mode = 0` 時主視窗就緒即關閉；`mode = 1` 時至少顯示 `duration_ms` 毫秒，時間到後才顯示主視窗，避免主視窗遮住啟動畫面。啟動畫面右下角會動態顯示目前版本號。

修改設定、名單、語言包或主題後，使用「檔案 > 重新整理程式狀態」。只要原選項仍有效，程式會保留目前模式、主題、語言、名單、結果與狀態；所選資源已移除時則回退到可用選項。

## 日誌與記憶

在「關於 > 記錄等級」選擇除錯、資訊、警告、錯誤或嚴重錯誤；低於所選等級的記錄會被過濾。「關於 > 程式日誌」會以唯讀方式開啟 `doc/log.log`，檔案更新時自動重新整理，可以一邊執行程式一邊查看。

「檔案 > 匯入記憶...」和「檔案 > 匯出記憶...」使用 JSON 儲存或還原最近結果，不會覆寫程式設定、名單或介面狀態。執行記憶檔為 `doc/memory.json`，只儲存各模式的最近結果。

說明文件、授權條款與程式日誌都在程式自身的唯讀檢視器中顯示。檢視器視窗會限制在桌面可用區域內，為工作列留出空間；支援觸控拖動捲動，並可透過 `[viewer]` 調整字號與重新整理間隔。

## 啟動與疑難排解

程式會先顯示啟動畫面，再檢查資料並初始化主視窗。設定、名單、語言或主題缺失時會使用備份或內建資料，只在狀態列和日誌中提示；程式本體元件缺失時才會彈出詳細錯誤並停止啟動。

編輯檔案後若選項無法使用，請執行「檔案 > 重新整理程式狀態」。若目前語言的說明檔不存在，「說明文件」會開啟英文版。「關於 > 回饋」包含 GitHub Issues 與電子郵件兩個項目；無法喚起郵件程式時會彈出視窗顯示電子郵件地址。
