# randname 說明

randname 是用於課堂點名的桌面程式。「模式」選單提供抽取、減量抽與滾動抽取。抽取模式可將人數設為 1，因此不再需要獨立的單抽模式。

## 抽取方式

- **抽取：** 使用數量旁的加減按鈕設定人數，再按「抽取」。同一次抽取不會重複選中同一人；下一次抽取會重新使用完整名單。人數設為 `1` 即可抽取一人。
- **減量抽：** 本次抽中的人會從目前執行期間的剩餘名單移除。「重設」會恢復目前名單。切換名單或重新整理後名單內容有變時，剩餘名單會重設。
- **滾動抽取：** 按「開始」輪播目前名單，按「停止」選取當下顯示的人。滾動速度由 `scroll_single.rate` 控制。

## 名單

從「名單」選單切換名單。名單設定位於 `config/name.toml`；每組名單有固定鍵名、多語言顯示名稱和人員清單：

```toml
[rosters.class_1.name]
en_US = "Class 1"
zh_CN = "一班"
zh_TW = "一班"

[rosters.class_1.names]
"student-001" = "王小明"
"student-002" = "陳小華"
```

每位人員須使用唯一鍵。名單名稱依目前介面語言、系統語言、英語、名單鍵名順序回退。主要名單無法使用時，程式會嘗試 `.name.default.toml`，最後使用內建的一人名單。

## 語言與主題

在「語言」選單選擇介面語言。語言包位於 `config/language.toml`，其中 `preferred` 指定啟動時的首選語言；當它與 `config/config.toml` 的 `app.language` 不同時，以 `language.toml` 的 `preferred` 為準（僅在未指定或無效時才使用後者）。英語為內建語言，語言檔缺失時仍可使用。切換語言會立即生效，不會清除目前抽取結果。

主題集中保存在 `config/theme.toml`，其中 `default` 設定預設回退主題；當它與 `config/config.toml` 的 `app.theme` 不同時，以 `theme.toml` 的 `default` 為準（僅在未指定或無效時才使用後者）。琥珀、藍色、深色、綠色、淺色與紫色主題各有 `-dark`、`-light` 版本，另有 Randname 粉紅主題。主題名稱與名單名稱使用相同的多語言回退順序。

## 設定

在 `config/config.toml` 設定啟動模式、名單、啟動畫面、視窗尺寸、滾動速度與日誌等級；主題與語言分別以 `theme.toml`、`language.toml` 獨立設定檔為準。尺寸模式 `screen_ratio` 依螢幕比例計算，`fixed` 則使用指定寬高。

```toml
[splash]
enabled = true
mode = 0
duration_ms = 1000
size_mode = "screen_ratio"
width = 480
height = 270

[window]
size_mode = "screen_ratio"
width = 800
height = 600
aspect_ratio = 1.5

[logging]
level = "INFO"
```

比例模式下，啟動畫面寬高不超過螢幕的四分之一；主視窗預設為 3:2，寬高不超過螢幕的四分之三。啟動畫面 `mode = 0` 時主視窗就緒即關閉，`mode = 1` 時至少顯示 `duration_ms` 毫秒。設為 `enabled = false` 可關閉啟動畫面。

修改設定、名單、語言包或主題後，使用「檔案 > 重新整理程式狀態」。只要原選項仍有效，程式會保留目前模式、主題、語言、名單、結果與狀態；所選資源已移除時則回退到可用選項。

## 日誌與記憶

在「關於 > 記錄等級」選擇除錯、資訊、警告、錯誤或嚴重錯誤；低於所選等級的記錄會被過濾。「關於 > 程式日誌」顯示本次啟動以來收集到的完整日誌。持久日誌位於 `doc/log.log`。

「檔案 > 匯入記憶」和「檔案 > 匯出記憶」使用 JSON 保存或還原最近結果，不會覆寫程式設定或名單。執行記憶檔為 `doc/memory.json`。

## 啟動與疑難排解

程式會先顯示啟動畫面，再檢查資料並初始化主視窗。設定、名單、語言或主題缺失時會使用備份或內建資料，只在狀態列和日誌中提示；程式本體元件缺失時才會彈出詳細錯誤並停止啟動。

編輯檔案後若選項無法使用，請執行「檔案 > 重新整理程式狀態」。說明文件與授權條款都會在 randname 自身視窗中顯示，不需要外部閱讀器。若目前語言的說明檔不存在，「說明文件」會開啟英文版。
