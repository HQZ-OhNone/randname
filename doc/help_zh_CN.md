# randname 帮助

randname 是用于课堂点名的桌面程序。“模式”菜单提供单抽、多抽、减量抽、滚动单抽、滚动多抽和滚动减量抽。

## 抽取方式

- **单抽：** 不是独立页面，而是自动切到多抽并把人数设为 `1` 的快捷方式。
- **多抽：** 使用数量旁的加减按钮设置人数，再按“抽取”。同一次抽取不会重复选中同一个人；下一次抽取会重新使用完整名单。
- **减量抽：** 本次抽中的人会从当前运行中的剩余名单移除。“重置”会恢复当前名单。切换名单或刷新后名单内容有变化时，剩余名单会重置。
- **滚动单抽：** 不是独立页面，而是自动切到滚动多抽并把人数设为 `1` 的快捷方式。
- **滚动多抽：** 先设置人数，按“抽取”后显示相应数量的转盘并同时轮播。按钮变为“停止（x/n）”，每按一次停下最前面的一个转盘并固定其名字；本轮已停下的名字不会再次出现。滚动速度由 `scroll.rate` 控制。
- **滚动减量抽：** 滚动方式与滚动多抽相同，但本轮抽中的名字会从剩余名单移除；右侧“重置”按钮恢复完整名单。滚动速度同样由 `scroll.rate` 控制。

输出框会保持窗口大小不变：名字能单行显示时单行显示；放不下且高度足够时自动换行；仍然放不下时，本次抽取会自动缩小字号。所有模式都使用这一规则。

## 名单

从“名单”菜单切换名单。名单配置位于 `config/name.toml`；每组名单有固定键名、多语言显示名称和人员列表：

```toml
[rosters.class_1.name]
en_US = "Class 1"
zh_CN = "一班"
zh_TW = "一班"

[rosters.class_1.names]
"student-001" = "王小明"
"student-002" = "陈小华"
```

每位人员须使用唯一键。名单名称按当前界面语言、系统语言、英语、名单键名的顺序回退。主名单不可用时，程序会尝试 `.name.default.toml`，最后使用内建的一人名单。

## 语言与主题

在“语言”菜单选择界面语言。语言包位于 `config/language.toml`，其中 `preferred` 指定首次启动的首选语言；旧配置中的 `app.language` 仅作为后备，`language.toml` 的 `preferred` 优先。英语为内建语言，即使语言文件缺失也可使用。切换语言立即生效，不会清除当前抽取结果。

主题集中保存在 `config/theme.toml`，其中 `default` 设置默认回退主题。主题名称与名单名称使用相同的多语言回退顺序。

记忆文件中的有效偏好（主题、语言、名单、模式、数量、日志等级、窗口尺寸）优先于配置文件，因此下一次启动会沿用上一次的选择。若希望每次都从配置文件读取，可在 `config/config.toml` 设置 `app.remember_preferences = false`。

## 窗口与状态栏

主窗口默认允许拖动边缘拉伸。拉伸后的尺寸会写入 `doc/memory.json`，下次启动恢复；将 `[window].remember_size` 设为 `false` 可关闭。窗口尺寸不会因为名字过长或导入记忆而改变。

状态栏左侧显示“抽取完成”等临时消息，右侧显示当前模式、名单、数量、主题、语言、日志等级和版本号。可在 `[statusbar]` 中逐项隐藏。

## 设置

在 `config/config.toml` 设置启动模式、名单、启动画面、窗口尺寸、输出字号、滚动速度、查看器、状态栏和日志等级；主题与语言分别以 `theme.toml`、`language.toml` 独立配置档为准。配置文件内每个选项都有中文注释。

```toml
[window]
size_mode = "screen_ratio"   # 或 "fixed"
screen_ratio = 0.75          # 初始尺寸占可用屏幕的比例
aspect_ratio = 1.5
width = 1000
height = 600
resizable = true
remember_size = true

[scroll]
rate = 30

[splash]
enabled = true
mode = 1
duration_ms = 1000
screen_ratio = 0.25
```

比例模式下，启动画面不超过可用屏幕的 `screen_ratio`；主窗口按 `screen_ratio` 与 `aspect_ratio` 计算初始尺寸。启动画面 `mode = 0` 时主窗口准备好即关闭，`mode = 1` 时至少显示 `duration_ms` 毫秒。启动画面右下角会动态显示当前版本号。

修改配置、名单、语言包或主题后，使用“文件 > 刷新程序状态”。只要原选项仍有效，程序会保留当前模式、主题、语言、名单、结果与状态；若所选资源已被移除，则回退到可用选项。

## 日志与记忆

在“关于 > 日志等级”选择调试、信息、警告、错误或严重错误；低于所选等级的记录会被过滤。“关于 > 程序日志”会以只读方式打开 `doc/log.log`，文件更新时自动刷新，可以一边运行程序一边查看。

“文件 > 导入记忆...”和“文件 > 导出记忆...”使用 JSON 保存或恢复最近结果，不会覆盖程序配置或名单。运行记忆文件为 `doc/memory.json`。

帮助、许可证和程序日志都在程序自身的只读查看器中显示。查看器窗口会限制在桌面可用区域内，为任务栏留出空间；支持触摸拖动滚动，并可通过 `[viewer]` 调整字号和刷新间隔。

## 启动与故障排除

程序先显示启动画面，再检查数据并初始化主窗口。配置、名单、语言或主题缺失时会使用备份或内建数据，并仅在状态栏和日志中提示；缺少程序本体组件时才弹出详细错误并停止启动。

编辑文件后若选项不可用，请执行“文件 > 刷新程序状态”。若当前语言的帮助文档不存在，“帮助”会打开英文文档。“关于 > 反馈”包含 GitHub Issues 与电子邮件两个条目；无法唤起邮件程序时会弹窗显示邮箱地址。
