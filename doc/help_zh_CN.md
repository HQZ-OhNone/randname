# randname 帮助

randname 是用于课堂点名的桌面程序。“模式”菜单提供抽取、减量抽和滚动抽取。抽取模式可将人数设为 1，因此不再需要单独的单抽模式。

## 抽取方式

- **抽取：** 使用数量旁的加减按钮设置人数，再按“抽取”。同一次抽取不会重复选中同一个人；下一次抽取会重新使用完整名单。人数设为 `1` 即可抽取一人。
- **减量抽：** 本次抽中的人会从当前运行中的剩余名单移除。“重置”会恢复当前名单。切换名单或刷新后名单内容有变化时，剩余名单会重置。
- **滚动抽取：** 按“开始”轮播当前名单，按“停止”选取当时显示的人。滚动速度由 `scroll_single.rate` 控制。

## 名单

从“名单”菜单切换名单。名单配置位于 `config/name.toml`；每组名单有固定键名、多语言显示名称和人员列表：

```toml
[rosters.class_1.name]
en_US = "Class 1"
zh_CN = "一班"
zh_TW = "一班"

[rosters.class_1.names]
"student-001" = "王小明"
"student-002" = "陈小华"
```

每位人员须使用唯一键。名单名称按当前界面语言、系统语言、英语、名单键名的顺序回退。主名单不可用时，程序会尝试 `.name.default.toml`，最后使用内建的一人名单。

## 语言与主题

在“语言”菜单选择界面语言。语言包位于 `config/language.toml`，其中 `preferred` 指定启动时首选语言；当它与 `config/config.toml` 的 `app.language` 不同时，以 `language.toml` 的 `preferred` 为准（仅当未指定或无效时才使用后者）。英语为内建语言，即使语言文件缺失也可使用。切换语言立即生效，不会清除当前抽取结果。

主题集中保存在 `config/theme.toml`，其中 `default` 设置默认回退主题；当它与 `config/config.toml` 的 `app.theme` 不同时，以 `theme.toml` 的 `default` 为准（仅当未指定或无效时才使用后者）。琥珀、蓝色、深色、绿色、浅色和紫色主题各有 `-dark`、`-light` 版本，并提供 Randname 粉色主题。主题名称与名单名称使用相同的多语言回退顺序。

## 设置

在 `config/config.toml` 设置启动模式、名单、启动画面、窗口尺寸、滚动速度和日志等级；主题与语言分别以 `theme.toml`、`language.toml` 独立配置档为准。尺寸模式 `screen_ratio` 按屏幕比例计算，`fixed` 使用指定宽高。

```toml
[splash]
enabled = true
mode = 0
duration_ms = 1000
size_mode = "screen_ratio"
width = 480
height = 270

[window]
size_mode = "screen_ratio"
width = 800
height = 600
aspect_ratio = 1.5

[logging]
level = "INFO"
```

比例模式下，启动画面宽高不超过屏幕的四分之一；主窗口默认 3:2，宽高不超过屏幕的四分之三。启动画面 `mode = 0` 时主窗口准备好即关闭，`mode = 1` 时至少显示 `duration_ms` 毫秒。`enabled = false` 可关闭启动画面。

修改配置、名单、语言包或主题后，使用“文件 > 刷新程序状态”。只要原选项仍有效，程序会保留当前模式、主题、语言、名单、结果与状态；若所选资源已被移除，则回退到可用选项。

## 日志与记忆

在“关于 > 日志等级”选择调试、信息、警告、错误或严重错误；低于所选等级的记录会被过滤。“关于 > 程序日志”显示本次启动以来收集到的完整日志。持久日志位于 `doc/log.log`。

“文件 > 导入记忆”和“文件 > 导出记忆”使用 JSON 保存或恢复最近结果，不会覆盖程序配置或名单。运行记忆文件为 `doc/memory.json`。

## 启动与故障排除

程序先显示启动画面，再检查数据并初始化主窗口。配置、名单、语言或主题缺失时会使用备份或内建数据，并仅在状态栏和日志中提示；缺少程序本体组件时才弹出详细错误并停止启动。

编辑文件后若选项不可用，请执行“文件 > 刷新程序状态”。帮助与许可证均在 randname 自身窗口中显示，不需要外部阅读器。若当前语言的帮助文档不存在，“帮助”会打开本英文文档。
